# FixNow

## Project Overview

FixNow is a real-time full-stack service request platform that connects customers with service providers such as electricians, plumbers, mechanics, and other service professionals.

Customers can create service requests, communicate with service providers, track service progress, and provide reviews.

Service providers can manage their profiles, receive service requests, accept jobs, communicate with customers, and update service status.

Administrators can manage users, service providers, service categories, and platform activity.

## Main User Roles

- Customer
- Service Provider
- Admin
